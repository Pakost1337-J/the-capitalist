# Иконки игры

Положите сюда PNG / JPG / WEBP / SVG файлы.

## Как подключить

1. Загрузите файл, например `kiosk.png`
2. В редакторе `/editor.html` у клетки укажите имя файла: `kiosk.png`
   или полный путь: `/assets/icons/kiosk.png`
3. Сохраните

## Примеры имён

| Файл | Для чего |
|------|----------|
| kiosk.png | Киоск |
| cafe.png | Кафе |
| bank.png | Банк |
| oil.png | Нефть |
| player1.png | Фишка игрока 1 |

Рекомендуемый размер: **64×64** или **128×128** px.
